## 🚀 Featured Projects

### 💰 SakuTrack

**A Minimalist Personal Finance Tracker**

SakuTrack is a personal finance tracking web application designed to help users manage their money, monitor expenses, and achieve their savings goals.

**Features:**

- 📊 Financial dashboard and cash flow statistics.
- 💸 Income, expense, and currency exchange tracking.
- 🎯 Savings goals and recommendations.
- 📈 Spending analysis and financial reports.
- 🔐 Authentication and cloud database with Supabase.
- 💾 Data backup and export.

**Tech Stack:**

`React.js` `Vite` `CSS` `Supabase`
